# Sky Exchange

Sports Trading Exchange Prototype

## Tech Stack
- **Backend:** .NET Web API
- **Frontend:** Next.js + TypeScript + Tailwind CSS
- **Database:** PostgreSQL (via Docker)
- **Realtime:** SignalR (WebSockets)

## Running Locally

### Backend
```bash
cd backend/SkyExchange
dotnet run
```

### Frontend
```bash
cd frontend/sky-exchange
npm run dev
```
